# Tujuan: reproduksi angka tesis. Angka analisis di `data/tanah-hilang.db` dihasilkan
# persis dari versi pustaka di bawah ini (venv .venv/ di akar repo, Python 3.14,
# dibekukan via `pip freeze` 2026-08-06). Menjalankan pipeline dengan versi pustaka
# geospasial (rasterio/GEOS) YANG BERBEDA tetap menghasilkan angka yang secara

#   python3 -m venv .venv
#   .venv/bin/pip install -r requirements.txt
#   .venv/bin/python -c "import rasterio, numpy, shapely; print('env OK')"
#   .venv/bin/python pipeline/00_prasyarat.py        # cek prasyarat data, bukan pustaka
